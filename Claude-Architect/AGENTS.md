# Instruções para agentes — curso Claude Certified Architect

Fonte de verdade deste diretório: **`Claude-Architect/CLAUDE.md`** (plano, formato, como conduzir) e
**`Claude-Architect/blueprint.md`** (o conteúdo do exame). Leia-os antes de agir.

Atalhos:
- Aula: `python3 engine/aula.py status` + `current` (guia em `engine/CLAUDE.md`).
- Quiz/prova/simulado: `python3 engine/session.py start <questions.json>` (ver `simulados/CLAUDE.md`).
- Curso **focado na prova**: sem práticas, sem API key. Teoria enxuta + muitas questões + simulados.
- Idioma: aula em PT-BR; quizzes, provas, simulados e mini-perguntas de checagem em **inglês** (ver CLAUDE.md).
- Exemplos de código em **C#** (linguagem-base), ou na linguagem salva em `.sessions/preferencias.json`.
- Progresso: `Claude-Architect/.sessions/`, commitado no fork/branch do aluno; `main` fica zerada.
